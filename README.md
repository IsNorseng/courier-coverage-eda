# Исследовательский анализ данных покрытия курьерских служб

Сравнение четырёх сетей доставки в Мексике. Проект показывает, как различается охват операторов, где доступна только одна служба и какая пара охватывает больше всего территорий из выборки. Службы обозначены буквами A–D.

- [Jupyter Notebook](courier-coverage.ipynb) с кодом на Python, подготовкой данных, графиками и выводами. Результаты сохранены в ячейках.
- [Интерактивный отчёт](courier-coverage.html) для просмотра в браузере. Переключатель показывает индекс Жаккара или число общих территорий. Таблицу регионов можно сортировать и фильтровать по названию.

## Результаты

| Показатель | Результат |
| --- | ---: |
| Территории с определённым регионом | 31 891 |
| Территории с одной службой | 16 531 (51,8%) |
| Территории с двумя службами и более | 15 360 (48,2%) |
| Территории со всеми четырьмя службами | 3 697 (11,6%) |

- **Служба D указана для 31 232 территорий.** В 16 092 из них в выборке нет других операторов. Это 50,5% всех территорий с определённым регионом.
- **Службы C и D дают наибольший охват среди пар.** Вместе в выгрузке они охватывают 31 876 из 31 891 территории (99,95%). Служба C добавляет 644 территории к охвату службы D.
- **Службы A и B имеют наибольшее относительное пересечение.** У пары 4 206 общих территорий из 9 166 в объединённой сети, индекс Жаккара составляет 45,9%. По абсолютному числу общих территорий лидируют службы C и D (12 380).
- **В Oaxaca на всех 1 840 территориях указана только служба D.** В Veracruz одна служба указана для 1 832 из 2 435 территорий (75,2%).

## Данные и методика

Источник — лист «ДатаФрейм» книги «EDA покрытия КС.xlsx», 157 955 записей. Дата среза в книге отсутствует. Территорией считается сочетание пятизначного почтового индекса и нормализованного региона. Знаменатель основных долевых показателей включает территории с определённым регионом. Для расчёта доли от всех индексов Мексики потребовался бы полный справочник.

1. Почтовые индексы приведены к пятизначному текстовому формату. В 1 643 строках добавлен ведущий ноль. Варианты написания региона сопоставлены по явному [словарю замен](data/state_aliases.csv). Названия федеральных единиц сохранены на испанском.
2. Из 321 записи без региона 219 сопоставлены по индексу с единственным известным регионом в той же книге. Остальные 102 записи исключены из основных расчётов. У одного оператора поле муниципалитета заполнено значением «Нет», поэтому детализация по муниципалитетам не используется.
3. Повторные сочетания «регион + индекс + служба» свёрнуты до одной записи. После исключений и дедупликации осталось 57 628 связей территории со службой.
4. Охват оператора — число территорий, где он указан, делённое на число территорий основной выборки. Индекс Жаккара — размер пересечения двух сетей, делённый на размер их объединения.

На записях с определённым регионом подсчёт только по индексу дал те же результаты. Если включить также 102 индекса без региона, получается 31 993 индекса. Для 15 360 из них (48,0%) указаны две службы и более.

## Воспроизведение

В архиве лежат агрегированные данные и выполненный ноутбук. Сохранённые графики доступны без исходного XLSX.

Для повторного расчёта распакуйте архив и откройте терминал в папке `courier-coverage`. Подойдёт Python 3.12, доступный по команде `python`. Положите свою копию книги в `data/EDA покрытия КС.xlsx` или укажите путь в первой ячейке с кодом.

```powershell
python -m pip install -r requirements.txt
python -m jupyterlab courier-coverage.ipynb
```

В Jupyter выберите **Run → Run All Cells**. Для обновления CSV, JSON и HTML можно отдельно запустить `python analysis.py "data/EDA покрытия КС.xlsx" --report courier-coverage.html`. Текстовые выводы в README и ноутбуке относятся к предоставленной книге.

| Файл | Содержание |
| --- | --- |
| [analysis.py](analysis.py) | Чтение XLSX, нормализация, агрегация и сверка итогов |
| [results.json](data/results.json) | Итоги, профиль источника и проверки чувствительности |
| [distribution.csv](data/distribution.csv), [carriers.csv](data/carriers.csv) | Распределение по числу служб и метрики операторов |
| [pairs.csv](data/pairs.csv), [postal_only_pairs.csv](data/postal_only_pairs.csv) | Пересечения, объединения и вклад второго оператора для двух ключей |
| [states.csv](data/states.csv) | Охват по регионам, детализация по службам, число и доля территорий с выбором |
| [state_aliases.csv](data/state_aliases.csv) | Правила нормализации и число строк по каждой замене |
